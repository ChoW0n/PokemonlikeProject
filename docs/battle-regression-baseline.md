# 전투 회귀 기준선

이 문서는 `PokemonBattle.Tests`가 보호하는 전투 규칙과 도감 데이터의 기준값을 기록한다. 표시용 설명이나 기술 분류만 추가해도 아래 런타임 계약을 깨뜨리지 않아야 한다.

## 기술 카탈로그

- 런타임 기술 카탈로그는 중복 없는 522개 항목으로 구성된다.
- 각 기술은 `MoveRuleMetadata`에서 전투 규칙이 분류되어야 한다. 보호, 날씨, 지형, 대타, 반격, 미러코트, 아이템 교환, 설치기와 제거기는 이름·설명만으로 동작하지 않는다.
- `StatChangeEntry.TargetsSelf`가 `true`이면 기술 사용자의 능력치를, `false`이면 상대의 능력치를 변경한다.
- 자기 능력치 하락 기술은 사용자의 단계가 내려가고, 하얀허브가 있으면 그 하락을 회복한 뒤 도구가 소비된다.
- 자기 능력치 상승 기술과 상대 능력치 하락 기술은 각각 효과 대상과 단계 변화 메시지가 일치해야 한다.

## 전투 규칙

- 버티기는 이번 턴에 받을 치명적인 피해를 HP 1로 남기며, 급소 여부와 관계없이 적용된다.
- 날씨 기술은 `BattleWeather`를 5턴 동안 갱신하고, 지형 기술은 `BattleField`를 5턴 동안 갱신한다.
- 리플렉터·빛의장막·오로라베일은 사용자의 진영에 설정되며, 빛의점토가 있으면 지속 턴이 연장된다.
- 보호 기술은 기술별 보호 효과를 가진다. 킹실드는 접촉한 공격자의 공격을 낮추고, 독가시방벽은 독을 부여하며, 가시방벽은 접촉 피해를 주고, 완강한거부는 방어를 낮춘다.
- 트릭룸·중력은 전투 필드 상태를 갱신한다. 카운터·미러코트는 해당 턴에 받은 물리·특수 피해만 각각 반사한다.
- 설치기는 상대 진영에 기록되고, 고속스핀은 설치기를 제거하면서 사용자의 스피드를 올린다. 대타출동은 HP를 소모해 피해와 일부 효과를 대신 받는다.
- 도발은 변화 기술을 제한하지만, 자기 진영에 적용되는 능력치 변화 기술은 상대 대상 기술로 취급하지 않는다.

## 능력과 도감 데이터

- 날카로운눈은 상대가 유발하는 명중률 하락을 차단한다.
- 미라클스킨은 상대가 사용하는 명중 기반 상태 기술의 명중률만 낮추며, 공격 기술과 자기 대상 기술에는 적용하지 않는다.
- 1대1 전투에서는 플러스·마이너스 등 아군 지원 능력이 상대를 아군으로 간주하지 않는다.
- 포켓몬 신장은 `PokemonHeightCatalog`를 통해 도감 데이터에 적용된다. Bulbasaur는 7dm, Wailord는 145dm이어야 하며, 이 값은 스프라이트 스케일 계산의 입력이다.
- 도감 배열 인덱스와 스프라이트·신장 카탈로그 인덱스는 서로 어긋나지 않아야 한다. 포켓몬 수를 늘리거나 도감 순서를 바꿀 때는 두 카탈로그를 함께 검증한다.

## 검증

```bash
dotnet test PokemonBattle.Tests/PokemonBattle.Tests.csproj --no-restore
```

이 기준선은 전투 규칙과 도감 데이터의 회귀 테스트와 함께 갱신한다. UI 표시 변경은 이 문서의 규칙을 우회하거나 기술 데이터를 임의의 기본값으로 대체해서는 안 된다.
