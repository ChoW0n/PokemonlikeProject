---
name: Enemy team scaling
description: The progression rule separating opponent team size from account unlock breadth.
---

Normal opponent team size must be derived from the current run round, not the account's total unlocked species. The unlock count may continue to influence the candidate pool, but it must never make a fresh run face a full team.

**Why:** Unlocks are account-wide and can be pre-granted by administration, while a new run still needs the intended early-game difficulty curve.

**How to apply:** Use the run's current stage/round for team cardinality and keep unlock-derived values limited to candidate diversity or other explicitly pool-related behavior. Preserve special rival lineups separately.
