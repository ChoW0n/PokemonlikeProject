---
name: GitHub change control
description: User-controlled policy for GitHub commits and pushes.
---

Do not create GitHub commits or push to GitHub automatically. Only perform either action after the user explicitly requests it.

**Why:** The user wants to review and control GitHub history and remote changes separately from implementation work.

**How to apply:** Make and verify workspace changes normally, but leave them uncommitted and unpushed unless the user directly asks for a commit or push.
